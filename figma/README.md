# Roomify — Figma Design Handoff

This folder contains Figma-ready UI boards for the Roomify frontend. Import the SVG boards into Figma and use them as the visual source of truth for the React/Tailwind implementation.

## Boards
- `01-Landing.svg` — landing page
- `02-Dashboard.svg` — saved designs dashboard
- `03-New-Design.svg` — room setup screen
- `04-Editor.svg` — interactive 2D editor

## Import into Figma
1. Open a new Figma Design file named **Roomify — UI Design**.
2. Create pages named `Landing`, `Dashboard`, `New Design`, and `Editor`.
3. Drag each SVG into its matching page.
4. Ungroup imported SVGs if you want to edit individual layers.
5. Use the design tokens below when refining components.

The SVGs are intentionally based on the existing Roomify information architecture and UI, so the Figma work stays aligned with the deployed React app rather than introducing a different product design.
